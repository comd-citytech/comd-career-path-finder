Skill chart

Which job skills each COMD class builds. The Career Path Finder uses this chart to show students how their classes connect to each job and which electives to take next.

To update a class: edit its entry in data/course-skills.json on GitHub and open a pull request. Under "builds", list the job skills the class teaches, copied word for word from that job's list under "jobs". The data check flags any skill that doesn't match.

Studio courses (3504, 4701, 4730, 4801, 4830, 4900) are shown with the skills they build, but every BFA student takes them, so they never change which electives the Path Finder recommends.
